## Tratamiento de datos

- Las descripciones del catálogo son síntesis manuales breves; el enlace conserva el texto original del empleador. El motor extrae señales de esas síntesis, de las publicaciones consultadas mediante la API de Get on Board o del texto importado desde Luk, según la procedencia.
- No se convirtió USD a CLP, bruto a líquido ni renta anual a mensual.
- La API y las siete fichas revisadas son vías de evidencia distintas. El [esquema oficial de Get on Board](https://www.getonbrd.com/doc/openapi.yaml) devuelve rangos que no identifican por sí solos su período de pago. La [guía salarial del portal](https://www.getonbrd.com/help/must-the-salary-offered-be-public-or-can-it-be-confidential) admite presentación mensual o anual. El adaptador mantiene esos rangos como texto con unidades pendientes, fuera de agregaciones numéricas; no les atribuye las unidades verificadas en otra ficha.
- Sólo se construyen grupos si hay monto, moneda y periodicidad explícitos. Se separan país, nivel declarado, tipo de vínculo y base bruto/líquido. Los grupos con menos de tres avisos muestran muestra pequeña.
- Los rangos pertenecen al conjunto de responsabilidades y requisitos del cargo. No prueban un premio salarial por una habilidad ni son medias de mercado.
- La muestra inicial fue seleccionada para cubrir una práctica, niveles iniciales y puestos avanzados. No es aleatoria ni representativa.
- La frecuencia de una habilidad cuenta publicaciones únicas de la muestra, excluye registros ficticios e históricos y no constituye un ranking nacional.
- La ruta de aprendizaje usa los requisitos del **cargo seleccionado**, no la suma de todos los cargos. Ausencia de evidencia en el perfil no equivale a ausencia de capacidad.
- Las oportunidades de experiencia mantienen condiciones de jornada, matrícula, experiencia, ubicación y tutoría. Se prioriza el país del perfil y se distingue falta de información de compatibilidad confirmada.

La búsqueda de Luk y la muestra salarial tienen orígenes y momentos distintos. Si una consulta nueva no publica renta, se muestra como desconocida; no se le imputa la renta de un cargo parecido.
